## 创意

**一句话**：不只是语音输入。六个编号段落快切，每段只讲一件事：一次真实的“按住 fn → 说话 → 松开”，加一张右侧的“Utter 设置”卡片，交代这件事对应哪项设置。节奏统一，镜头只做轻微推近，信息靠编号标签、顶部字幕和设置卡片三层传达，静音也能看懂。

## 产品事实核对

| 表述 | 依据 |
|---|---|
| 三种输出模式 | `OutputMode`：原文直出 / 智能整理 / 语音指令（`mode.*` 文案），在“通用设置”中切换 |
| 语音指令读取屏幕 | `VoicePipelinePolicy.shouldCaptureScreenContext`：`.command` 时总会读取；需要屏幕录制权限，页脚已注明 |
| fn + shift 翻译 | `HotkeyManager`：按主键时如果同时按着翻译修饰键，就进入 `.translation`；默认修饰键是 shift（`defaultTranslationModifier`）。HUD 文案“翻译中…”（`pipeline.translating`） |
| 翻译目标语言 | `TranslationLanguage`：英语、简体中文、繁体中文、日语、韩语、西班牙语、法语、德语 |
| 行业词库 | `industry.lexicon.*`：通用、医疗、法律、金融财会、软件技术 |
| 语言风格 | `LanguageStyle`：口语 / 专业 / 自定义 |
| 本地与远程模型 | 截图来自 `review-evidence/.../light.png`；远程服务商列表见 README。页脚注明“使用远程 API 时，文本会发送给所选服务商” |

## 披露

页脚依次为：“界面为动画重建 · 示例文本 · 实际效果取决于所选模型”；语音指令段为“需屏幕录制权限”；模型段为远程 API 的数据去向说明。片中没有速度数字。
