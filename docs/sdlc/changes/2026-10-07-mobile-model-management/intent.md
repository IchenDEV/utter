# Intent: iOS 模型页对齐系统风格、可选用语音模型、支持整形模型

**Status:** approved
**Approved-by:** 用户（本对话：“全部批准，继续执行。”）
**Approved-date:** 2026-10-07
**Risk:** medium（新增模型下载与端侧推理入口；不改权限、不改桥协议）
**Upstream:** 用户（本对话，2026-10-07）：“模型下载那边你是一点也没改，现在的交互不大符合 iPad OS 或者 iOS 的设计风格，这个下载按钮也比较奇怪。另外呢，下载之后我也没法选择这个模型作为语音模型。另外呢，我还要支持下载那个整形模型。对你的模型列表呢，你就参考桌面版本就可以了。”
上游 bundle：`2026-10-04-ios-support`、`2026-10-06-keyboard-streaming-dictation`（整形目前只有 Apple 系统模型）。

## Problem

1. 模型页是自制按钮样式（文字按钮“下载/取消/使用模型/删除”），不是 iOS 设置里常见的列表交互。
2. 下载完成后“选用”要点另一个按钮，且选用会走“关闭语音输入”的重配置路径；用户反馈选不上。**本轮没有复现**（模拟器上 Whisper 下载、选用、重启、删除的旧用例是通过的），所以修复依据是设计，不是复现。
3. 只有少数 Whisper 与一部分 MLX 语音模型；没有整形模型可下载，整形只能用 Apple 系统模型（部分设备不可用）。
4. 手机的模型列表是手挑的子集，与桌面不一致。

## Outcome

可验收的结果：

1. 模型页是 iOS 分组列表：已下载的行点一下即选用，所选行右侧是对勾；未下载的行右侧是云下载图标；下载中是带停止方块的进度环，点击取消；失败/暂停显示原因并可重试；左滑或长按删除并二次确认。
2. 选用语音模型不再关闭语音输入；下一次听写开始时才读取所选模型。删除正在使用的模型回退到系统识别。
3. 列表来自桌面同一份目录：Whisper 全部档位、MLX 语音模型（Qwen3-ASR、Confucius4-R2T2、FireRedASR2、Mega-ASR）、MLX 文本模型（Qwen3/3.5 系列等，旧型号折叠）；本机装不下的模型标明原因并不可下载，不是隐藏。
4. “文字整形”分区：系统语言模型 + 可下载的本地文本模型；选一个后，键盘听写结束后的整形用它；失败保留原文。设置页显示当前整形模型。
5. 目录名称与简介跟随系统语言（此前桌面目录默认中文）。

## 范围外

- 不改桥协议、权限、键盘外观。
- 不承诺本地 MLX 整形模型在后台待命（画中画）下可运行、不承诺延迟与质量；这些没有真机数据。
- 不做手动导入模型、不做云端整形。

## 验收标准

1. UI 测试：模型页显示 Whisper、更多识别模型、文字整形三个分区；`model.download.mlx-community/Qwen3.5-0.8B…` 可见；`settings.polish.model` 可见（iPhone Air、iPad mini 模拟器）。
2. UI 测试：Whisper tiny 下载 → 点击选用 → 对勾 → 重启仍选中 → 左滑删除并确认 → 回到可下载。
3. UI 测试：下载可取消并重试。
4. 本机不满足内存的模型不可下载并显示原因（由 `DeviceCapability` 的 iOS 可用内存系数决定）。
5. 文档如实写明：真机、后台、MLX 整形质量均未验证。
