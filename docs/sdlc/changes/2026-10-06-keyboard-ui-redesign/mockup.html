Utter 语音键盘 · 界面重设计

每块键盘面板按 744 × 300 pt 绘制，等比例缩放展示；右下角为切换键盘键。每个方向展示就绪 / 录音中 / 结果 / 待命失效四态，并覆盖浅色与深色。文案语义、无障碍标识符和行为保持不变。

推荐：方向 A「原生键盘」 — 键帽与材质和系统键盘同语言，无论浅色深色、任何宿主 App 里都不突兀；录音态用整块红色键帽 + 波形给出明确进行时反馈；状态收敛为左上角一枚状态点胶囊。方向 B 更雅致但可用键更少、信息密度低；方向 C 保留大按钮个性，但仍是“App 感”，和宿主键盘并排时违和。

现状（对照）

不透明白底 + 居中一行说明文字 + 88pt 纯黑圆形麦克风 + 散落的无边框小图标 + tertiary 文本块。问题：像设置表单，不像键盘；录音中没有任何进行时反馈。

方向 A · 原生键盘

系统键盘材质（浅 #D1D4DA / 深 #43474D）+ 标准键帽（白/深灰、1.5pt 底影）。左上角状态点胶囊；主行是「删除键 · 宽语音键 · 换行键」，录音时语音键整块变红并内嵌波形；结果态换成结果卡片 + 蓝色「插入」键帽；待命失效时语音键置灰、右侧出现「打开 Utter」链接键帽。
