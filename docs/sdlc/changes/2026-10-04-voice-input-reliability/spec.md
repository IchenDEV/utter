## 设计范围与模块边界

本设计覆盖 [F1–F11 验收用例](acceptance-cases.md)，保留已批准 intent 的全部
行为决定。设计已获批准，实现前仍须批准后续 plan。本文中的状态、阈值
和接口变化是设计契约，不代表修复、模型评测或本机验收已经通过。

当前分支已把处理、词库、模型、原生服务和共享会话抽为独立模块，但桌面
`VoicePipeline` 与集成入口仍保留旧协调路径。数字证据解析、保真策略选择、
交付结果和手势状态属于结构边界；词库数据、中文 OCR 级别、回复开场白
属于模块内缺陷。修复不得分别复制到新旧流水线。

| 方案 | 实现与验证成本 | 迁移、运行和维护成本 | 选择 |
| --- | --- | --- | --- |
| 在每个入口继续打补丁 | 首次较低，重复覆盖桌面/CLI/共享会话 | 保留双轨状态、错误成功语义和重复提示词 | 不采用 |
| 收敛模块契约，模块内部局部修复 | 数字、策略、交付和手势需契约测试；复用现有引擎 | 适配入口后删除旧逻辑；普通模式不增加推理次数 | 采用 |
| 整体重写 | 权限、录音、模型、输出全部重新验证 | 数据与原生行为迁移范围大，无法缩小当前缺陷边界 | 不采用 |

依 Ponytail `full`：复用 `TranscriptFidelityGuard`、`PromptBuilder`、个人词典
snapshot、现有 Qwen context、`ModeRecipeService`、模型租约及
`DeliveryReceipt`；使用 Foundation、Vision、ScreenCaptureKit、Accessibility
和已锁定 SDK。只补必要的证据值、可观察结果与评测宿主，不引入另一套
插件系统、事实数据库、模型框架或通用规则 DSL。

| 唯一责任模块 | 行为契约 |
| --- | --- |
| `UtterContracts` / `UtterMediaContracts` | 处理决策、交付证据、手势模式事件等不可变值；无引擎和 UI 实现 |
| `UtterProcessing` | 数字/单位证据、保真策略、生成与清理、清单分类、翻译语言检查；所有入口调用同一实现 |
| `UtterData` | 词库与个人词典 snapshot、优先级和明确纠正映射 |
| `UtterWhisper` / `UtterMLX` / `UtterModels` | 本地资产完整性、实际 tokenizer/EOS 加载、内存适配与生命周期 |
| `UtterMacServices` | 全屏采集、OCR、按键、输出事务、交付观察；不决定整理或编辑语义 |
| `UtterSession` | 单次会话、模式切换、取消、路由、交付与历史的一致性 |
| 桌面呈现与评测宿主 | 消费处理/交付结果；不再判断保真、复制提示词或把事件发出当写入成功 |

与插件化改造共用一次入口迁移；旧入口在过渡期只适配契约，不保留另一套
数字检查、模式判断或输出实现。最终删除失效 helper 和 `.shared` 依赖；
该语音修复 bundle 的通过不能替代整个插件化目标的验收。

## 内容保真：数字、单位与事实

数值证据使用同一解析结果服务保护 token、单位检查和内容比较，避免多套
正则分别认定“数字”。每项携带原文范围、规范数值、类型、单位及相邻内容
锚点。类型区分数量、钟点、日期、序数、百分比和版本；规范化只用于比较，
不改写原文，也不让无依据的模型输出补充原始证据。

| 原文证据 | 可接受的等价形式 | 必须拒绝的变化 |
| --- | --- | --- |
| 周五下午三点；三点二十分 | 周五下午 3 点；3 点 20 分 | 换成 4 点、3.2、30 分或删除下午 |
| 三件事、三项任务、三条建议、三号开会 | 对应 3 件、3 项、3 条、3 号 | 数值改变、件换项、日期换数量 |
| 版本二点五；百分之三；六月三号 | 版本 2.5；3%；6 月 3 号 | 小数当时间、3% 变 3、日期错位 |
| Alice 两项、Bob 三项 | Alice 2 项、Bob 3 项 | Alice 3 项、Bob 2 项，即使总数集合相同 |
| 第一次来，第二天走 | 等价序数表达，仍是叙事 | 凭空分成第 1、2 条任务 |

复用现有中文数字解析，扩展上下文证据与单位表。先识别明确钟点/日期，
再识别小数，避免贪婪吞掉“点二十分”。孤立“一、三”须有数值上下文；
“一点意见”“统一处理”、标识符、电话号码、URL 与路径不能被宽泛替换。
列表生成的行首编号是结构标记，仅在已有清单契约、项数和项内容匹配时
排除出事实数字；正文中的序数仍受保护。比较不能只用排序后的数值集合。

普通整理保留事实、单位、对象关系与否定语义。允许格式等价、明确的口误
自我修正及已授权词典纠正；不放宽为任意同义替换。短句沿用同样证据规则，
不以字数短直接拒绝。拒绝时交付当前准备后的原文，维持静默回退；内部
结果记录拒绝原因，普通日志不记录整句原文或模型输出。

自定义非空风格与自定义非空 system prompt 统一选择“只限制新增事实”的
策略。允许任意删减、重排和表达变化；候选中的数字/实体/单位关系必须有
原文依据，允许原文的这些证据被删除。现有要求源 token 必须全部保留的
有序子序列检查不再用于此策略，也不以长度、重合率或否定词计数限制删减。

该策略增加一次事实支持检查：在确定性证据检查通过后，使用本次冻结的
同一生成提供者和模型，对“原文、候选”检查候选是否增加人物、时间、
数量、承诺或其他陈述。使用独立固定提示词，输入作为数据隔离，不沿用
用户自定义指令；严格解析 `supported / unsupported / uncertain` 结果及
新增陈述依据。删除内容不是违规。只有 `supported` 可交付候选；检查异常、
超限、格式错误或不确定均静默回退。取消须传播，不启动备用远端服务。

事实检查的输入长度受既有模型上下文限制，不截断原文后宣称有依据；不能
完整检查时回退。额外推理仅用于上述自定义转换，耗时计入处理阶段。
模型判断可能误判，不能承诺形式化证明所有自然语言事实不新增；固定负例、
人工标注和真实模型评测共同限定可验收的质量范围。

## 词库、清单和回复语义

软件词库增加 Kubernetes、Redis 及明确的“库伯内提斯 → Kubernetes”纠正
映射。复用现有词库 schema，不把所有术语自动推导成任意音译匹配。输入
准备时应用一次纠正，之后保真比较使用同一准备结果；不得输出后再次替换
造成递归扩写。个人词典优先于行业映射，冲突、大小写、边界、重复和长度
限制由唯一 snapshot 决定。不相关词库条目不是新增术语的授权。

Qwen 沿用当前 `configureRecognition` → 有限 phrases → runtime context 路径，
补生产传递和回声恢复测试；真实音频对照评测区分“上下文已传入”和“识别
质量提高”。其他 ASR 只用各自支持的入口，不声称全部引擎支持热词。

`TextFormatClassifier` 对枚举标记采用边界和条目结构证据，避免 `contains`
把“第一次/第二天”判成步骤。清单提示词保留原文明说的总述句，随后列项；
修订示例与保真规则同时验证，不能通过删总述绕过保真。口语/专业风格保持
不同表达要求，用人工标注的真实输出评价效果，快照仅验证提示词契约。

普通“帮我回复”进入新回复模式，即使存在上一段输出、选区或历史锚点也
不自动编辑。编辑路由同时要求原指令的改写/替换/删除操作、明确对象及
模型解析的一致结果：例如“把刚才那段改正式”“替换选中的内容”，且目标
租约仍有效。“回复这封邮件”仍是新回复。不能只因 resolver
返回 `rewrite_last` 就替换；无明确对象则生成新内容或要求指定对象。

“以下是回复：”等开场白只在生成命令结果的清理路径处理；原文整理中确实
口述这些文字时保留。优先解析现有 `final_text` 包络，兼容已知纯文本
开场白，不全局删除正文中的同名短语。取消、锚点过期和目标变化均禁止
自动替换；沿用现有编辑与延后整理的历史、租约和幂等契约。

## 全屏上下文与权限

使用 ScreenCaptureKit 采集全部可用显示器，按稳定显示器顺序构成同一份
全屏 snapshot；单屏即完整显示器。排除 Utter HUD 所属窗口，包括动态
创建、隐藏后重现及多屏 HUD。窗口身份来自本应用窗口注册，不靠 OCR
删文字；无法确定 HUD 过滤时跳过该次采集并给出可操作错误。

OCR 默认 `.accurate`，在目标系统查询当前 Vision revision 支持语言，再
设置其支持的中文与英文组合。不支持或识别失败与“屏幕没有文本”分开；
不静默降级到不支持中文的配置。结果合并保留屏幕边界和阅读顺序，并复用
现有上下文长度限制；逐屏 OCR，图像模式按现有尺寸上限合成全屏图像，
沿用同一 HUD 排除与显示器集合。

`ScreenCaptureService` 返回区分权限拒绝、采集失败、无内容与成功的结果。
权限检查沿用 `SCShareableContent.current`；明确启用的读屏请求缺少权限时
显示系统设置入口。普通整理不强行请求读屏权限。快照属于会话，取消和
提供者关闭时释放，不缓存到用户历史；远端发送仍受已有设置授权控制。

## 本地模型的加载与停止

Whisper 模型安装完成包含 Core ML 权重与匹配 variant 的 tokenizer 数据，
由模型目录与完整性检查统一拥有。既有缺 tokenizer 的安装标为需修复，
保留已有权重；用户通过模型下载/修复入口补齐，不在录音时偷偷下载。

锁定 SDK 的 `ModelUtilities.loadTokenizer` 在本地解析失败后会转向 Hub；
因此不只设置 `tokenizerFolder` 或 `download: false`。本地工厂先使用本地
解析器验证并创建 tokenizer，以 `load: false`、`prewarm: false`、
`download: false` 初始化 WhisperKit，在加载模型前注入 tokenizer，避开
SDK 的联网回退。缺失或损坏直接返回模型修复错误，禁止调用 Hub 下载入口。
保持已有资源租约、取消后的 drain 和模型文件替换保护。

Gemma 4 从冻结的本地目录构建 `ModelConfiguration(directory: …,
extraEOSTokens: ["<turn|>"])` 并传入真实工厂。通过 SDK 的 configuration
入口与拒绝下载的 downloader 加载，模型和 tokenizer 均为目录来源；不能
改用远端模型 ID 换取停止配置。保留模型自带 EOS，验证额外 token 可解析且
实际生成在此停止；最大 token 上限继续作为兜底。删除未调用的旧 helper。

模型目录以运行内存需求和设备统一内存筛选默认推荐；不拿下载体积当运行
内存。Llama 4 保留目录条目与手动选择，但普通内存 Mac 不默认推荐；不足
时说明需求并推荐可运行选项。估计不等于实际加载保证，峰值内存需模型实测。

## 录音、组合键与翻译

按主键立即启动音频采集；1000ms 是组合键分类宽限，不是推迟录音的时间。
手势有唯一 ID 和单调时钟。宽限内按 Shift 归类为翻译；听写采集已开始且
主键仍按住时，晚按 Shift 也可单向切换为翻译。先按 Shift 再按 Fn 同样
有效；Shift 松开不降回听写、不停音频，Fn 松开才结束长按录音。

模式切换是同一会话的显式事件，不创建第二次 admission、不重启音频、不
重新读取设置。目标语言和所有候选模式所需配置在 admission 时冻结，停止
后拒绝迟到切换。toggle/double-tap 保留各自开始/停止方式；切换后不得因
起始 action 不同而无法停止。用注入时钟覆盖 999/1000/1001ms 边界。

Fn+方向键等系统组合键事件继续送往系统，同时取消本次暂定录音并丢弃
音频，不输出或入历史。Fn 单独按键与地球键系统动作冲突时，设置页面提示
将系统“按下地球键”设为“无操作”并提供入口，不修改系统设置。事件 tap
如何识别系统组合键必须由真实 macOS 窗口验证，不靠固定延时猜测。

录音结束先收齐已接受的音频回调和尾部缓冲，再识别；模型准备不丢弃已采集
首段。未获麦克风权限或设备错误显示准确状态，不谎称正在录音。启动期间
明确呈现准备模型或等待权限，不能笼统显示“仍在处理”。

翻译生成后用系统语言识别检查目标语言，正文目标语言置信度至少 0.7 且
比其他语言高至少 0.2 才确认为成功；源语言与目标语言相同的配置不视为
错误。数字、URL、代码和专名不
单独判为错语言；只有这些内容的结果标为语言不可判定。错误语言、不足以
证明完成翻译的普通短句不能按成功翻译写入，保留结果供显式复制。翻译
不套用原文字符重合率检查；数字、实体和事实保持使用翻译专属契约与评测。

## 写入事务、剪贴板与 HUD

沿用 `prepare → commit → receipt`，同一 operation ID 最多提交一次；
目标租约验证与第一次外部副作用构成提交边界。receipt 记录副作用集合
及确认依据，包括剪贴板修改、粘贴指令和直接文本修改；写剪贴板即已跨过
边界，不能等发出粘贴才登记。后续副作用仍须验证会话与目标，但不能因为
已有副作用而开启新事务。不把 `Cmd+V` 已发送或 AX 调用返回成功等同于确认。
副作用之前失败为 `notCommitted`，副作用之后不能确认结果为 `uncertain`。

优先使用目标支持的 AX 选区/文本写入，只修改目标范围并读取结果确认，
不能替换整个文档。每次修改前复核目标和范围；AX 返回失败但可能已有
副作用时不自动改走粘贴。安全输入提前检测，拒绝模拟键盘写入，给出原因。

剪贴板产品选择：保留自动粘贴兼容能力，新增可关闭的“允许剪贴板粘贴”
选项；默认开启以兼容现有输入体验。设置说明回退文本可能被剪贴板管理器
记录；关闭时只直接写入，不支持的目标显示“无法直接写入”和显式复制
入口。显式复制也会暴露给管理器，不能承诺阻止第三方记录。

自动粘贴前保存所有原剪贴板 items，写入待交付文本，登记 changeCount；
发出粘贴前复核该计数，已被其他应用修改时禁止粘贴。已明确未发出粘贴
且未修改目标的失败/取消，可以在仍拥有 changeCount 时撤销临时剪贴板。
有可观察目标时，通过原目标的文本/范围变化确认交付，观察上限 3 秒；
仅在确认完成且 changeCount 仍归本次写入时恢复旧剪贴板。超时、无法观察
或已发出粘贴后取消：返回 `uncertain`，不恢复可能尚未读取的旧内容，不
自动重试，保留待交付文本供恢复。若其他应用改剪贴板，绝不覆盖其修改。
上限约束等待时长，不能当作“已粘贴”的证据。关闭观察任务须 drain。

HUD 根据 receipt 和 error 类型呈现：确认插入为“完成”；显式复制为
“已复制”；不确定为“未确认写入，请检查目标应用”，提供复制入口并说明
不要重复输入；未提交说明权限、目标、模型或设备原因。错误保留至用户
关闭或开始新操作，不立即隐藏。对不确定交付不创建可自动替换的锚点，
历史记录明确其交付状态，不能计入成功写入统计。

## 评测入口、耗时与验收边界

提供独立 macOS 评测宿主，复用生产插件注册、`ModeRecipeService` 和生成
服务，不通过当前会提交输出的 CLI/XPC 请求绕行。评测宿主不注册真实输出、
麦克风、屏幕、个人历史或个人词典写服务；使用样本注入的上下文与词典。
只使用明确指定的已安装模型；默认禁止下载和远端请求，不读取用户口述。

输入 JSONL 支持转写文本或获准音频、模式/风格、词库、注入屏幕文本、
gold 事实/术语、允许的表达和禁止变化。固定合成集至少包括每个 F3–F8
正反例，以及 20 条允许删减和 20 条新增事实负例；模型名称、资产指纹、
完整有效提示词及生成参数随运行 manifest 记录，排除密钥与真实用户数据。

生产处理结果增加可选诊断观察：记录原始生成、清理候选、策略决策、回退
原因、最终文本及阶段耗时。普通生产不保存这些正文；评测明确启用后输出
合成样本结果。评测中的最终文本是“待交付文本”，不得称为真实光标写入。
复用 `evaluate-voice-quality.py` 的 CER/WER、术语和延迟字段；补充回退率、
事实新增及对象错配指标。现有数字 multiset 指标不能证明对象关系正确，
其要求所有数字保留的指标也不用于评价自定义删减是否合格。

质量门槛：宣传片时间/数量/术语例句在固定模型配置下各运行 5 次，全部
保留预期事实并成功整理；固定新增数字、实体、承诺、对象错配负例零个
危险结果进入待交付文本；合法自定义删减通过率至少 95%。风格、清单、
回复及翻译由冻结标注逐项判定，文本参考不要求逐字一致。规则桩测试不能
替代此门槛；模型、配置、样本数量与所有失败必须随报告公开。

每次真实评测显式限制样本数、最大输出 token 和单例时限，取消即 drain
在途生成；普通 CI 不下载大模型或运行付费评测。真实模型任务单独启动，
每个未运行的模型留为未验证，不能用另一模型成绩代替。

以单调时钟从 Fn 松开事件统计至 confirmed insertion 的总耗时；复制、
不确定和失败分别统计至各自结果，不混入完成延迟。分段包含排队、准备、
尾部收齐、ASR、主生成、事实检查和输出观察。冷/热启动分别报告；基准
使用生产完整提示词及短/中/长代表样本，分别报告 p50/p95，不用极短提示词
宣称用户端速度。

单元与提示词测试覆盖 F3/F4/F5/F6 的规则及输入优先级；带桩提供者和共享
会话测试覆盖模式切换、错误路由、取消、权限拒绝、模型缺失及交付状态。
输出故障注入覆盖提交前失败、提交后取消、慢粘贴、剪贴板被第三方更改、
目标切换、重复提交和未知结果；故障后不得重试已产生副作用的操作。

macOS CI 必须通过 SDLC、basic checks、Swift 测试和 release-style build；
可运行合成截图 OCR 测试，但不能冒充真实 TCC、麦克风或全局按键验证。
用户在 macOS 26 Apple Silicon 验收全屏/多屏 HUD、权限拒绝与重新授权、
首尾音频、系统 Fn 组合键、安全输入、真实应用慢粘贴、冷缓存断网及
Gemma 停止行为。涉及呈现的路径补实际窗口截图和操作证据。

## 风险、独立验证与回滚

独立验证者重点审阅全屏远端边界、剪贴板残留、取消后副作用、事实检查
局限与真实硬件证据。该角色由后续计划明确，不以作者自测替代；生产仍
需要高风险变更的人类批准。现阶段不扩大权限或隐式上传评测数据。

分模块交付可独立撤销，回滚选择恢复上一已验证提交，不保留运行时双轨
feature flag。新增设置使用默认值兼容旧安装，历史状态字段兼容旧记录；
模型补齐为增量资产，不删除现有权重。回滚前 drain 会话及观察任务，
保存原数据与受影响模型目录；不能把回滚当作撤销已写入目标或已被第三方
记录的剪贴板文本。必要时关闭剪贴板回退/读屏等能力并通过明确提示恢复。
