## 所需测试能力

| 能力 | 验收要求 |
| --- | --- |
| 模拟 LLM | 注入确定输出、错误、超时和取消；经过真实清理与保真路径 |
| 屏幕上下文注入 | 使用合成邮件、选区和 HUD 样本；不读取用户真实屏幕 |
| 宣传片回归语料 | 固定时间、清单、混排、术语、回复例句，配对应改动/新增事实负例 |
| Mac 真实模型批跑 | 明确选择已安装模型，复用生产处理服务，输出可接入现有评分脚本的 JSONL |
| 提示词快照 | 使用完整生产提示词，覆盖普通/专业/自定义、清单、词库、翻译和编辑 |
| 按键时钟与事件桩 | 确定性复现 1000ms 边界、晚按、先松 Shift、Fn+方向键和取消 |
| 交付与权限故障注入 | 区分确认交付、失败和不确定；验证 HUD、历史、锚点、剪贴板与取消 |
| 分段性能计时 | 记录松键、准备、识别、生成、交付终点；冷/热分组，报告 p50/p95 |

规则、提示词和带桩测试在 CI 运行；无预装模型的 CI 不声称通过真实模型
评测。真实窗口、权限提示、麦克风、离线缓存和模型质量由用户本机验收。
