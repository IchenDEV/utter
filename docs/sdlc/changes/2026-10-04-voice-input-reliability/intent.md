# Intent: 修复语音输入的内容保真、指令和交付可靠性

**Status:** approved
**Approved-by:** User (conversation: “批准语音修复 intent”)
**Approved-date:** 2026-10-04
**Upstream:** 用户 2026-10-04 的 F1–F11 问题清单与行为决定；[插件化 intent](../2026-10-03-builtin-plugin-composition/intent.md)。
**Risk:** high — 涉及全屏内容、麦克风权限、全局按键和剪贴板交付；首批数字与词库修复属于 medium。

## Problem

智能整理的提示词与保真检查不一致，合法的中文数字格式转换会静默退回原始
转写。行业术语纠正、读屏回复、组合键、离线模型和输出状态也存在缺口，
现有规则测试不能证明真实模型和 macOS 交互路径可用。

当前分支已核对的边界如下。用户报告中的其他问题保留为验收用例，尚未在
macOS 26 Apple Silicon 机器上复现的项目不视为已证实的运行时故障。

| 边界 | 当前证据 | 影响 |
| --- | --- | --- |
| 中文数字 | 直接运行现有 `TranscriptFidelityGuard`：三点、三件、三项、三条、三号的阿拉伯数字转换均得到 `protected_token_change`；二点五转换通过 | 格式整理合法输出被退回 |
| 软件词库 | 内置资源没有 Kubernetes、Redis、库伯内提斯条目 | 宣传片示例缺少术语与纠正依据 |
| Qwen3-ASR 上下文 | 当前 `QwenNativeASREngine` 已实现 `configureRecognition`，并把 phrases 转成 runtime 的 context | 必须验证实际生产路径和识别收益，不能据此认定完全不支持术语 |
| 中文读屏 | `ScreenOCR` 设置 `.fast`，截屏过滤器没有排除窗口 | 中文可读性和 HUD 污染需要验证 |
| 回复路由 | resolver 提示词要求明确编辑对象，但 `rewrite_last` 的说明包含“回复” | 仅有提示词不能保证第二次回复不会覆盖上一段 |
| 翻译键 | 当前宽限 100ms；Shift 松开会结束翻译 gesture；已开始听写后没有切换分支 | 晚按和先松开 Shift 会丢失预期行为 |
| Gemma 4 | `modelConfiguration(for:)` 定义 `<turn\|>`，加载路径没有调用它 | 停止符配置是否生效缺少证据 |
| Whisper 离线 | 加载配置没有显式指定本地 tokenizer 来源 | 冷缓存断网运行需要验证 |
| 质量评测 | `scripts/evaluate-voice-quality.py` 读取已有 ASR/整理 JSONL 并打分，不调用模型 | 缺少使用生产处理路径批量生成评测输出的入口 |

Apple 文档说明识别级别与 API revision 共同决定语言支持，因此要在目标系统
查询支持语言并验证中文截图，不能仅凭设置 `recognitionLanguages` 判定可用。
参考：[Recognizing Text in Images](https://developer.apple.com/documentation/vision/recognizing-text-in-images)。

## Outcome

视频中的时间、数量和技术术语可以整理后正常写入；新增或改变的数字、实体
和事实仍受保护。读屏回复、翻译录音、离线运行和交付结果有可重复的验收
证据。每个修复只保留一套生效的行为，接入正在建设的可替换插件与共享会话。

## Scope

- F1–F11，具体例句、预期结果、测试类型和当前证据见
  [acceptance-cases.md](acceptance-cases.md)。
- 首批：数字保真检查与生产路径评测入口；随后补充术语及音译纠正。
- 接着验证并修复中文读屏、回复路由和模型离线加载/停止行为。
- 再处理输出交付、HUD、录音按键、翻译以及总耗时统计。
- 复用现有评测指标、模型服务、配置、词库替换和会话测试能力。
- 保留原插件化目标，不增加动态插件安装或第二套处理流水线。

## Constraints

用户已明确决定的行为，不再作为开放问题：

1. 整理输出未通过保真检查时，**静默退回原文**。
2. 自定义风格可以大幅改写和删减；**不以删减量作为拒绝理由，只拦截新增事实**。
3. 翻译组合键宽限为 **1000ms**；**录音开始后晚按 Shift 允许切换到翻译**。
4. 读屏采用**全屏**，不限制为当前窗口；**排除 Utter HUD**。
5. 使用 GitHub macOS CI，真实窗口、TCC、麦克风及本地模型由用户之后在
   macOS 26 Apple Silicon 本机验证。

保持本地优先、既有设置和数据兼容、个人词典优先、上下文长度边界、提示词
回声保护、会话取消与交付事务边界。全屏内容仅用于明确启用的读屏请求；
不扩大已有远端发送授权。录音切换模式不丢音频、不重启录音、不重新读取
本次会话已冻结的用户设置。

工程测试与模型质量评测分开验收。普通测试不下载大模型、不调用付费服务。
真实评测明确选择已安装模型，记录模型版本、完整提示词配置和冷/热状态；
评测不向真实光标写入内容，不读取真实屏幕，不写用户历史或个人词典。
评测产物默认只含合成或获准样本，不保存用户屏幕和口述日志。

## Acceptance criteria

1. 时间、件/项/条/号、序数、小数、日期和百分比可按证据转成数字；数值
   替换、无依据新增数字、单位改变及数字与对象错配继续被拒绝。
2. Kubernetes、Redis 及明确音译映射可用；纠正后的术语不被检查误退回。
   个人词典优先，短句和中英混排不被不相关词库条目污染。
3. 自定义风格的合法缩写和删减通过；新增数字、实体和无依据事实的样例
   被拒绝。不得把规则测试通过描述为已证明所有自然语言事实保持不变。
4. 清单保留原文明说的总述句；叙事中的“第一次”“第二天”不变成列表。
5. 中文邮件可读，HUD 不进入上下文；缺少权限有可操作提示。“帮我回复”
   不因存在上一段输出而覆盖它；只有明确编辑对象的命令可替换内容。
6. 生成回复不携带“以下是回复：”等脚手架；原文确实包含这些字样时不误删。
7. Fn 录音保留开头和结尾；Fn+方向键不触发口述。1000ms 内的组合键与
   已开始录音后的 Shift 切换都有效；先松开 Shift 不中断，Fn 松开才结束。
   翻译输出语言经过检测，错语言结果不能被当成成功翻译写入。
8. HUD 只在交付已确认时显示成功。安全输入、麦克风错误、模型缺失、
   拒绝权限和交付不确定有准确的状态与处理入口，不能静默显示完成。
9. 粘贴完成前不恢复旧剪贴板；保护其他应用的剪贴板更改。审阅剪贴板管理器
   可见性并明确必要的产品选择，不承诺阻止第三方记录已写入剪贴板的文本。
10. 已下载 Whisper 在冷 tokenizer 缓存、断网条件下可加载；Gemma 4 使用
    真实停止配置并在结束 token 停止。模型推荐和可运行判断符合设备内存，
    不把 Llama 4 作为普通内存 Mac 的默认推荐。
11. 统计松开录音键至交付确认的总耗时，覆盖冷启动和热启动；基准测试使用
    生产提示词和代表性长度，分别报告准备、识别、生成和交付耗时。
12. 批量真实模型评测复用生产处理服务，输出原始模型结果、实际交付文本、
    是否回退及分段耗时，能接入现有指标脚本。宣传片例句和负例形成固定
    数据集；故障注入与带桩测试覆盖取消、权限拒绝、错误路由和写入失败。
13. 必须通过 `bash scripts/sdlc-checks.sh`、`bash scripts/ci-basic-checks.sh`、
    `swift test` 和 macOS release-style build。涉及原生行为的结论以 CI 和
    用户本机验收为准；权限/隐私路径需要独立验证与明确回滚方案。
