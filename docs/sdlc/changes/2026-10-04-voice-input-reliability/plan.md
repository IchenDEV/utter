## 实施边界与依赖

依据已批准的 [intent](intent.md)、[spec](spec.md) 和
[F1–F11 用例](acceptance-cases.md) 实施；本文件已批准，按以下边界开始实现。
plan 一次批准覆盖以下全部工作项，不为每批局部修复另设审批阶段。

复用现有模块与 SDK，模块级契约替换和内部修复结合。先编写能区分正确与
错误行为的契约测试，再改实现；不把旧入口、新入口分别修成两套逻辑。
桌面入口和呈现尚未完成的插件化迁移与本计划协调一次实施，不能等共享
服务测试通过后就宣称用户实际使用路径已修好。

M1 与 M2 同批推进；M3 复用其处理决策与评测接口。M4/M5 复用已存在的
屏幕、模型和会话租约。M6 先建立交付证据，M7 再让 HUD/按键/耗时消费
统一结果。M8 完成入口收敛，M9 汇总质量、原生验收与独立验证。

## Work items

### M1 — 统一数字与事实证据（F3、F4）

- [ ] 在 `UtterProcessingTests` 补时间、件/项/条/号、日期、百分比、序数、
  小数与版本正例；补改值、改单位、对象数字交换、歧义“点”、孤立中文
  数字、URL/标识符和清单结构编号负例。保留现有多语言、口误纠正测试。
- [ ] 收敛 `TranscriptNumberEvidence`、`TranscriptMeasurementEvidence` 和
  protected token 的数字来源；扩展现有中文解析器与单位表，保留范围、
  类型、单位和对象锚点。只在比较时规范化，不改写原文以掩盖错误。
- [ ] 在真实处理服务桩中验证合法候选被接受、危险候选静默回退；回退文案
  不进入 HUD。新增结构化处理决策与原因，替代仅返回最终字符串的隐含判断。
- [ ] 修复 `TextFormatClassifier` 的枚举边界及清单提示词，保留总述句，
  覆盖“第一次来，第二天走”成对负例。数字政策和清单分类只保留各一处。

完成条件：F3.1–F3.5 与 F4 规则、快照和带桩流水线通过；新增/错配数字
仍被拦截。真实模型整理效果由 M2/M9 验证，不以规则测试代替。

### M2 — 生产路径评测与诊断（F3–F8、测试基础设施）

- [ ] 扩展 `ProcessingResult` 的可选诊断结果，分别记录原始生成、清理
  候选、策略决策、最终待交付文本和分段耗时；默认关闭正文记录，按操作
  隔离观察，取消后不向其他请求串写结果。消费方统一从结果读取状态。
- [ ] 建立固定合成 JSONL 语料与 schema 校验：宣传片时间/数量/术语、
  清单/叙事、风格、连续回复、翻译及对应负例；至少 20 条合法删减和
  20 条新增事实负例。标注允许表达、禁止变化和对象关系，不只给一条 gold。
- [ ] 新增独立 macOS 评测 executable，复用生产注册与 `ModeRecipeService`，
  注入词典、屏幕和内存上下文；不注册真实输出、麦克风、屏幕采集、历史
  或词典写服务。安装模型由明确目录及模型 ID 指定，无隐式下载/远端回退。
- [ ] 在 `scripts/` 提供构建/运行入口，复用 release-style Metal 资源构建
  方式；输出 manifest 和 JSONL，记录版本、资产指纹、完整提示词与参数，
  排除密钥。缺模型、超时、中断或未运行的用例不能记为通过。
- [ ] 复用 `evaluate-voice-quality.py`，补回退率、事实新增、对象错配与分段
  延迟；自定义删减不使用“所有源数字必须保留”的指标。为 schema、指标、
  样本错配、缺失结果和预算限制添加脚本测试。
- [ ] 先用模拟生成服务验证 runner 确实经过生产清理与校验、无真实副作用。
  主生成、事实检查分别可注入错误/取消。真实质量任务明确区分完整生成
  与固定危险候选的防线评测，避免因模型恰好没有新增事实而误判防线有效。

完成条件：八项测试能力均有对应入口或可注入 seam；桩运行生成可评分的
报告。真实评测需显式选择已安装模型和预算，普通 CI 不执行付费或大模型任务。

### M3 — 词库、自定义风格与新增事实（F5、F6）

- [ ] 补 Kubernetes、Redis 与明确音译纠正；测试个人词典优先、短句/词边界、
  大小写、冲突、重复和上下文长度限制。输入纠正一次，校验基于相同准备结果。
- [ ] 在 Qwen 原有 context 链路增加生产传递测试，覆盖空词库、有限 phrases、
  prompt 回声恢复及取消；不再建立第二条热词注入路径。
- [ ] 统一非空 custom style/system 的策略选择；先测试允许删除数字/实体及
  重排，再实现候选事实有源文依据的方向检查，不保留有序子序列或删减量限制。
- [ ] 在 `UtterProcessing` 增加固定的事实支持提示词与严格结果解析，借用
  本会话冻结的同一提供者/模型执行检查；输入超限、格式错误、异常和不确定
  静默回退。取消继续传播，普通风格不增加该次推理，不扩张远端授权。
- [ ] 测试删去内容、同义改写、改变数字、新增人物/日期/承诺、反转剩余事实、
  候选中的指令注入及检查超时；用完整提示词快照覆盖口语/专业/自定义差异。

完成条件：资源、策略、故障和生产桩测试通过；Qwen 识别收益及自定义合法
删减至少 95% 的质量门槛留给真实评测，不能宣称规则证明一般事实保持。

### M4 — 全屏读屏与安全回复路由（F7）

- [ ] 在共享编辑路由先补普通回复/明确编辑成对测试：有旧锚点、有选区、
  连续两次回复、目标已变化、锚点过期。运行时同时验证操作与对象证据，
  不能只相信 resolver 的 `rewrite_last`；“回复这封邮件”产生新回复。
- [ ] 为命令生成路径补“以下是回复：”清理与 `final_text` 包络测试，原文
  真正口述的同名短语保留。移除普通整理与编辑入口中重复的清理规则。
- [ ] 扩展屏幕结果，区分权限拒绝、采集失败、无文本与成功；以窗口注册身份
  排除 HUD，遍历全部显示器，逐屏 OCR，图像按现有尺寸边界合成。
- [ ] 采用 `.accurate` 并查询 revision 支持语言；以合成中英邮件截图测试
  OCR 与阅读顺序。注入多屏/HUD、过滤失败、取消和拒绝权限场景，验证
  无越权采集、无截图写入历史、无会话结束后的快照或回调残留。
- [ ] 在桌面提供本地化错误和系统设置入口，远端屏幕内容仍遵循原授权；
  实际窗口/HUD 与 TCC 提示交由 M9 本机验证。

完成条件：错误路由不产生替换副作用，中文 OCR 合成用例及权限状态测试
通过；CI 截图识别不得冒充真实全屏、权限或多屏窗口验收。

### M5 — 本地模型完整性与停止（F10）

- [ ] 模型资产契约纳入 Whisper variant 匹配 tokenizer；旧安装缺文件只标记
  需修复，下载/修复入口增量补齐。测试缺失、损坏、variant 错误及取消，
  保留已有权重和冻结租约，不能只查 `tokenizer.json` 存在。
- [ ] 用 SDK 本地解析器创建 tokenizer，初始化 WhisperKit 时关闭 load、
  prewarm 和 download，再注入 tokenizer 并加载模型；契约桩使任何 Hub
  请求直接失败，证明正常本地加载和损坏路径均不会偷偷联网。
- [ ] 本地注入补齐被 SDK tokenizer 加载路径同时执行的初始化：校验实际
  variant、tokenizer 匹配和 decoder 的 `isModelMultilingual`，测试中文及
  英语专用模型。不能因跳过联网入口而保留 SDK 默认 tiny/非多语状态；
  引擎元数据以实际模型维度及安装身份为准，不读取未初始化的 SDK 默认值。
- [ ] Gemma 4 使用本地目录 configuration 和拒绝下载的 downloader，把
  `<turn|>` 加入真实加载/生成配置；测试配置传入、token 解析、停止和上限
  兜底。删除未调用 helper，模型切换/重载仍遵循现有借用与 drain 规则。
- [ ] 模型推荐使用运行内存要求与设备内存，覆盖不同内存设备和不足提示；
  Llama 4 不进入普通内存 Mac 默认推荐，保留手动选择与目录兼容性。

完成条件：加载与推荐契约、故障测试通过；冷 tokenizer 缓存断网及真实
Gemma EOS 停止必须提供 M9 实测，拒绝网络的桩不是实际模型加载证据。

### M6 — 交付事务与剪贴板（F9、F2）

- [ ] 先扩展 `DeliveryReceipt` 的副作用集合和确认依据，覆盖首次剪贴板
  写入、后续粘贴/直接修改、幂等重放和取消。提交前失败与提交后不确定
  区分；测试旧 control、目标变化、重复 commit 均不会产生第二次副作用。
- [ ] 原生输出优先目标支持的 AX 范围写入，并观察原目标内容确认；不能
  改写整个文档。安全输入提前拒绝模拟按键，可能产生副作用的 AX 失败
  不再自动重试粘贴。所有插入、替换、删除与撤销共享此交付后端。
- [ ] 注入 pasteboard、目标观察、键盘提交和时钟，测试慢于 300ms 的读取、
  3 秒超时、不可观察目标、发出粘贴后的取消、第三方 changeCount 变化。
  只在明确安全时撤销临时剪贴板或在确认后恢复原 items，清理任务须 drain。
- [ ] 增加持久化“允许剪贴板粘贴”设置，默认开启；关闭时使用直接写入或
  显式复制。测试默认兼容、冻结设置和提供者替换；中英文说明管理器可见性。
- [ ] 不确定结果不自动重试、不创建可替换锚点、不记成功写入；历史保留
  明确交付状态，旧记录兼容读取。显式复制与实际插入保持不同确认语义。

完成条件：F9 故障注入与会话交付测试通过；真实应用确认能力、慢粘贴和
管理器可见性由 M9 验证，事件已发出不能作为成功证据。

### M7 — 按键、翻译、HUD 与总耗时（F1、F2、F8、F11）

- [ ] 为手势注入单调时钟/事件，补 Fn/Shift 两种先后次序、999/1000/1001ms、
  录音后晚按、先松 Shift、Fn+方向键、toggle/double-tap 及重复/迟到事件。
- [ ] Fn 立即采集，1000ms 只负责组合键分类；同一会话单向切为翻译，保留
  音频和冻结配置。Shift 松开不停录音，停止后拒绝切换；系统组合键取消
  暂定录音且继续传给系统。提供地球键冲突的本地化设置指引，不改系统设置。
- [ ] 结束录音先 drain 已接受的音频和尾部缓冲；测试模型准备中松键、
  麦克风启动失败/权限拒绝、设备退出，避免启动状态误报和音频首尾被截。
- [ ] 翻译验证复用系统语言识别，目标置信度 0.7、差值 0.2；测试正确/错误
  目标语、源目标相同、短句、专名/数字/代码及不可判定结果。非成功结果
  保留显式复制入口，不按成功翻译提交。
- [ ] HUD 唯一消费会话/receipt 投影：准备、录音、错误、已复制、不确定和
  完成准确区分。错误保留至用户关闭或新操作；提供对应权限/模型处理入口，
  本地化全部用户文案，不由 UI 再猜插入结果。
- [ ] 从 Fn 松开记录至各类终点的单调耗时，分解排队、准备、尾部、ASR、
  主生成、事实检查和交付；只对确认插入统计完成延迟。基准复用完整生产
  提示词，短/中/长及冷/热分组报告样本数、p50/p95。

完成条件：按键、会话、输出投影和计时桩通过；真实 Fn 系统行为、音频、
窗口及推理速度由 M9 验收，不能以桩耗时宣称实际性能。

### M8 — 入口收敛与兼容检查

- [ ] 核对桌面 Fn、翻译、选区编辑、延后整理、HTTP、XPC、CLI 和评测入口，
  每条均只调用共享策略/会话/交付服务；补真实入口到对应提供者的契约测试。
- [ ] 与插件化迁移同步删除失效的 `VoicePipeline`、`InputSessionCoordinator`
  逻辑及兼容 helper；过渡适配只能转换值，不能重做路由、保真或成功判断。
  更新模块边界检查和实际 owner 文档，不遗留可被调用的旧生产实现。
- [ ] 复验冻结模型、客户端撤权、设置切换、取消 drain、历史原记录更新和
  延后替换契约；保留 `OpenType` 包/兼容标识及现有外部协议行为。

完成条件：生产入口与替换提供者的端到端契约通过；只有一套真实生效的
处理/交付逻辑，现有用户数据可读取，插件化仍按其完整范围单独验收。

### M9 — 质量、原生验收与独立验证

- [ ] 完成下表工程检查及真实模型报告，把每个 acceptance case 的结果链接
  写入 `verification.md`；未运行、硬件 skip 和残余风险明确保留。
- [ ] 为用户提供本机验收入口和合成样本：真实窗口/多屏 HUD、权限拒绝与
  重新授权、Fn 组合键、首尾音频、安全输入、慢粘贴/管理器、冷缓存断网、
  Gemma EOS；呈现变化记录实际窗口的浅/深色及相关窄宽度证据。
- [ ] 独立验证由非实现者的 PR 审阅者承担，按
  [review-policy.md](../../review-policy.md) 从已批准契约审阅实际 diff，复跑
  权限、屏幕远端边界、剪贴板残留、取消后副作用和事实检查关键用例。
  用户负责已约定的本机操作验收；作者自测和 CI 不代替独立结论。
- [ ] 在提出 PR 前核对目标分支最新状态并消除冲突；保持各批次可独立回滚。
  全部修复、证据和独立结论齐备后，verification 才可标为待批准。

| 独立验证 | 非实现者只读审阅 + 关键检查复跑 | findings 全部解决或由用户明确接受，列明证据缺口 |

实际模型任务先校验资产、schema 与预算，再开始推理；默认最多 100 次单例
执行、每例 120 秒、输出上限 4096 token、总预算 60 分钟，可显式调整。
宣传片 5 次重复计入执行预算；事实检查的额外推理计入 token 与耗时预算。
中断输出部分报告并保留未完成状态，不把缺少结果算通过。真实数据样本需
获准，不用实际屏幕或口述自动充实语料。基线与修复结果使用相同模型、
资产与配置对比；无法在某模型完成的验收只标该模型未验证。

每批相关检查通过后继续下一批，不因文档或无关变更重复整套模型评测。
共享契约、故障、依赖或原生行为有新增改动时才扩大验证；交付前全套测试
与 macOS release-style build 必须针对最终提交通过。SwiftPM 命令顺序运行，
避免共用 `.build` 目录时相互占锁。使用 `gh` 操作 GitHub，不使用浏览器。

## Rollback

各批保留明确提交边界，回滚到上一已验证提交；不保留运行时新旧双轨。
回滚前停用并 drain 会话、模型借用、屏幕和交付观察任务；备份用户数据及
新增字段，模型修复只新增资产，不删除权重。新设置和交付状态须兼容旧
记录；测试旧数据读取与回滚后的模型可用性。对已写入目标或被第三方
记录的剪贴板内容不承诺撤回，必要时明确关闭对应能力并提示恢复操作。
