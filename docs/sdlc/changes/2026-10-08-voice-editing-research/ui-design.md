# 桌面“编辑选区”审阅界面设计(原型说明)

状态:原型草案,待负责人评审。`desktop-review-prototype.html` 是纯静态、无网络依赖的**模拟**页面:不使用麦克风,不连接真实宿主或模型,不能证明 AX 写回、剪贴板、恢复或延迟。

## 范围
仅纯文本选区。流程:捕获宿主选区 -> 复用现有录音 -> 显示识别到的口令 -> 并排预览原文与候选 -> 显式“应用”或“取消” -> 确认结果 -> 仅在目标与文本未变时一次性“恢复原文”。

固定演示数据:原文 `妈妈说周末一起吃饭，记得带上蛋糕🎂。`,口令 `改得更礼貌，保留时间和蛋糕`,候选 `妈妈说周末想一起吃饭，麻烦记得带上蛋糕🎂，谢谢。`(演示用,非模型输出)。

## 布局
单个审阅面板,无仿窗口外壳:流程步骤 -> 目标信息 -> 原文 / 候选(宽屏左右,窄屏上下) -> 识别口令 -> 状态消息 -> 按钮行。其下的虚线区“模拟夹具”只服务评审,不属于产品界面。

## 状态与按钮
| 状态 | 可用 | 禁用或隐藏 |
|---|---|---|
| 已捕获 | 开始录音(模拟)、取消 | 应用 |
| 录音中 | 停止并识别(模拟)、取消 | 应用 |
| 预览(正常) | 应用、重新录音、取消 | - |
| 预览(空结果/失败) | 重新生成候选、重新录音、取消 | 应用禁用 |
| 失效(stale) | 重新捕获选区、取消 | 应用禁用,录音隐藏 |
| 已应用 | 恢复原文(仅一次)、关闭 | 应用隐藏 |
| 已恢复 | 关闭 | 恢复禁用 |
| 结果不确定 | 关闭 | 应用、重试、录音全部不可用;不自动重试 |
| 已取消 | 重新捕获选区、关闭 | 原文未改动 |

候选失败只允许重算候选,绝不写宿主。恢复时若夹具设为“用户已改动/换焦点”,则拒绝恢复并消耗该次机会,不写入。

## 键盘与无障碍
- Esc 在应用前取消;Enter 只会激活当前聚焦按钮,文本区域按 Enter 无效果,不存在默认提交。
- 状态变化后焦点移到面板标题;原文与候选为可聚焦的滚动区域(`tabindex=0`、`role=region`),长文本 `max-height` 内滚动,不裁切。
- 状态消息写入 `role=status` 的 `aria-live=polite` 区域;步骤用 `aria-current="step"`;全部为原生 `button`/`input`。
- 状态不只靠颜色:有文字、禁用态与“(已完成)”标记。浅色/深色跟随系统。

## 字体与色彩
系统字体栈(`-apple-system`、PingFang SC),不加载外部字体;正文 15px,选区文本 17px,行高 1.6 至 1.7。中性暖灰底,单一深青绿强调色用于“应用”,红/琥珀仅用于错误/警示。无渐变、阴影、徽章、装饰动画。

## 夹具控制
候选:正常/空结果/失败;选区:示例句/超长文本;应用:成功/不确定;确认后宿主:未变/已改动;按钮“模拟:宿主选区已改变”触发失效;“重置原型”。

## 未知项
- 口令是否可编辑,仍待决定(原型为只读,仅可重新录音)。
- 真实面板形态(浮层/独立窗口)、焦点是否离开宿主,需真实宿主测试。
- 未做 VoiceOver、真实窗口浅/深色、窄宽度截图;仅做脚本语法检查。
- 恢复条件(同目标且文本等于候选)在此只是夹具开关,真实判定见 spec。
