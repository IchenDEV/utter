# Mac 语音验收

使用 macOS 26 的 Apple Silicon Mac 和 CI 产出的应用包。先安装所选识别和
整理模型，保留当前应用与配置备份，以便退出新版本后恢复。

| 操作 | 预期结果 |
| --- | --- |
| 按住 Fn，立即说“周五下午三点开会”，松开 | 开头与尾字完整；整理为“周五下午 3 点开会”，交付确认后显示完成 |
| 连说“三件事、三项任务、三条建议、三号见” | 合法数字转换可写入；数量与对象保持对应 |
| 选择软件词库，说 Kubernetes 音译和 Redis | 术语纠正可被接受；Qwen 的真实识别收益另用音频评测比较 |
| “今天定了三件事：第一……第二……第三……” | 保留总述句并生成编号条目 |
| “我第一次来，第二天就走了” | 保持叙事，不变成清单 |
| 自定义风格要求缩短；再测试无依据新增人物、日期或承诺 | 合法删减通过；危险候选静默回退，结果与报告中的决策一致 |
| 中文邮件占据屏幕，连续两次说“帮我回复” | 两次都生成新回复；无“以下是回复：”开场白，不覆盖上一段 |
| 明确说“把上一段输入改成……”；改变目标窗口后重试 | 只在目标与锚点仍有效时替换；失效目标不改动旧内容 |
| 多显示器分别放置中英文本；录音时保持 HUD 可见 | 上下文包含各显示器文字，排除实际 HUD 窗口 |
| 拒绝屏幕权限后请求回复 | HUD 保留可操作错误，不继续生成或写入；授权后重试可用 |
| 录音后约 2 秒按 Shift；先松 Shift，再松 Fn | 同一次录音切换翻译；Shift 松开不中断，Fn 松开结束 |
| Fn+方向键，以及已设置系统地球键动作的 Fn | 系统组合键正常；按键冲突可按设置页指引调整，无误插入 |
| 模型冷准备时立即说话并松 Fn | 保留已接受的首段与尾段音频，停止后不重新开始录音 |
| 拒绝麦克风权限、拔掉输入设备、未安装模型 | 显示对应错误与处理入口，错误保持可见，不显示完成 |
| 返回错误目标语言、短专名或纯数字的翻译 | 不把未确认目标语言的候选当成功翻译写入；可显式复制 |
| 普通文本框、长文档中间选区、安全输入字段 | 支持时只修改范围；安全输入不模拟粘贴，复制与插入状态区分 |
| 慢于 300ms 的粘贴目标、无法观察内容的目标 | 不提前恢复剪贴板；不确定结果不自动重试，不建立成功锚点 |
| 粘贴等待期间由另一应用更改剪贴板 | 保留另一应用的新内容，不恢复覆盖它 |
| 关闭“允许剪贴板粘贴”，同时启用剪贴板管理器 | 自动输出使用支持的直接写入；显式复制按用户操作进行，管理器仍可能看到写入内容 |
| 使用 Whisper 匹配 tokenizer 的完整目录，清空 SDK tokenizer 缓存并断网冷启动 | 正常本地加载与识别；损坏 tokenizer 显示需修复，不尝试隐式下载 |
| 安装 Gemma 4，运行短答与长答，断网重载再测试 | 实际结束 token 生效；停止符与输出上限都可结束生成 |
| 不同内存设备检查模型推荐和 Llama 4 | 建议符合运行内存要求，普通内存 Mac 不默认推荐 Llama 4 |
| HTTP/XPC/CLI、Fn 与遥控麦克风交替请求并取消 | 共用忙状态；取消等待清理，旧连接不能停止后来的会话 |
| 浅色/深色设置页、录音/复制/不确定/错误 HUD | 文本、按钮完整可读；模型和权限入口可用，无裁切 |

使用[本地评测](voice-evaluation.md)保留完整模型报告、冷/热耗时及事实复核。
记录每项使用的应用提交、系统版本、模型、目标应用、实际结果和证据。

不覆盖实际权限、多屏、麦克风或目标应用行为。

回滚时退出应用，恢复先前的签名应用；插件配置变更可从同目录的备份恢复。
不删除历史、词典或模型文件。重新使用应用时复核系统权限授予的签名身份。
