$ utter features --list

The features are the pipeline.

  • ⌘

    Global hotkey

    Press and hold fn (or your key of choice) in any text field — Mail, Slack, Xcode, Notes. Hold, speak, release.

  • ✎

    Verbatim or smart format

    Get the transcript exactly as spoken, or let the LLM polish it into finished prose. Your call, every time.

  • ⇄

    One-key translation

    A second hotkey turns what you say into a translation in your target language — no app switching, no pasting.

  • ◇

    Voice command mode

    Reply, summarize, proofread, format a table, or list action items by voice — with what's on screen as context.

  • ⌗

    Screen context OCR

    Reads nearby on-screen text to better understand names, project terms, and homophones.

  • ▤

    Memory & personal dictionary

    Correction learning, an industry lexicon, and input history keep names and phrases exactly the way you write them.

  • ⚙

    Smart model recommendations

    Checks your Mac's chip, memory, GPU, and disk space, then highlights which models run well — and warns about those that won't.

  • ∿

    Streaming recognition (beta)

    Partial transcripts appear while you speak — near-instant feedback on supported engines.

  • ◎

    Bilingual UI

    The interface switches between English and 简体中文, and recognition covers many languages.

  • ⇥

    Inserts anywhere

    Text is typed at your cursor via the Accessibility API, with a clipboard-paste fallback for stubborn fields.

$ utter faq

Questions, answered.

What is Utter?

A native macOS menu bar app that turns your voice into polished text in any app. Hold a hotkey, speak, and the result is typed directly at your cursor.

How is Utter different from Apple's built-in dictation?

Utter adds LLM cleanup, screen context via OCR, one-key translation, voice command mode, and global hotkey insertion into any app — all with local models by default.

Does Utter work offline?

Yes. With WhisperKit, Apple Speech, or local Qwen3-ASR plus a local MLX model, Utter transcribes and refines text entirely on-device. Remote providers are optional.

Which macOS version and hardware does Utter require?

macOS 26 or later on Apple Silicon. Intel Macs are not supported. Utter checks your chip, RAM, GPU, and disk space and shows which models are compatible.

Which apps does Utter work in?

Any macOS app that accepts text input. Utter uses the Accessibility API, with a clipboard-paste fallback.

Which languages does Utter support?

Speech recognition supports many languages via WhisperKit, Apple Speech, and Qwen3-ASR. The app UI is bilingual in English and Simplified Chinese.

Is Utter free and open source?

Yes. Utter is MIT-licensed and the full source is on GitHub.
